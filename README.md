# SupportHub [Work in Progress]

A desktop application built with **WPF**, adhering to the **MVVM** pattern and utilizing **Generic Host** to ensure a clean and structured codebase.

## Tech Stack & Architecture
* **C# / .NET**
* **WPF** (User Interface)
* **MVVM Pattern**: Used for a clean separation between the UI and business logic.
* **.NET Generic Host**: For dependency injection and lifecycle management.
* **API Integration**: Currently in development.

## Project Status
This project is an active **Work in Progress (WIP)**. Both the core architectural foundation and the API integrations are currently being built and refined.
